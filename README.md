## Overview

The system predicts equipment failures using a Decision Tree Machine Learning model and supports preventative maintenance planning through a web-based management platform.

## Technologies

- Angular
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- Python FastAPI
- Scikit-Learn
- SMTP Email Notifications

## Features

- User Management (CRUD)
- Equipment Management (CRUD)
- Machine Failure Prediction
- Prediction History
- Email Notifications
- Notification History
- Audit Trail
- Dashboard Metrics
